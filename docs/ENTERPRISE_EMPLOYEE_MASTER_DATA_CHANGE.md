# 企业级员工主数据变更治理

版权所有 © 2026 上海如静知华信息科技有限公司（[知华科技官网](https://www.zhuatech.cn/)）。

## 业务目标

统一控制员工身份、组织岗位、薪酬和工资账户等高影响主数据变更，防止未经授权的薪资变化、账户替换、越权查看或跨周期数据不一致。

## 强制控制

- 员工关系状态、变更依据、身份字段和组织岗位批准必须有效。
- 仅在薪酬或工资账户确实受影响时触发对应审批与回拨核验。
- 个税社保、生效周期、个人信息最小必要和下游系统影响必须复核。
- 人力资源负责人必须批准，经办和复核必须职责分离。
- 申请、核验、审批与生效必须形成完整审计证据链。

## 接口与结果

`POST /api/enterprise/ehr/employee-master-data-change`

返回 `APPLY`、`REVIEW` 或 `BLOCKED`。薪资、银行、税务、社保和身份系统仅预留适配器，项目不内置真实外部凭据。
